# JH PDF2MD

把 PDF 轉成結構化 Markdown 的 Windows 小工具。

它會辨識標題、段落、清單、表格、程式碼、連結與圖片，自動去掉每頁重複的頁首、頁尾和頁碼，並把被換行或換頁切斷的句子接回去。中文和英文文件都適用。

## 下載

到 [Releases](https://github.com/JianHuangLyu/JH-PDF2MD/releases/latest) 下載最新的 zip，解壓縮後得到 `JH PDF2MD.exe`。

它是單一執行檔，不需要安裝 Python 或其他軟體。需要 64 位元的 Windows，目前在 Windows 11 上測試過。

**注意**：執行檔沒有數位簽章，第一次執行時 Windows 可能會顯示「Windows 已保護您的電腦」。點「其他資訊」再點「仍要執行」即可。

## 使用方式

### 雙擊執行

直接開啟 `JH PDF2MD.exe`，在跳出的視窗中選擇一個或多個 PDF。

### 拖放

把 PDF 檔或整個資料夾拖到 `JH PDF2MD.exe` 的圖示上。

這兩種方式都會把結果存在原本的 PDF 旁邊：`報告.pdf` 會產生 `報告.md`，圖片則放在 `報告_images` 資料夾。

### 命令列

需要調整選項或批次處理時，可以在終端機執行：

```bat
:: 轉換單一檔案
"JH PDF2MD.exe" 報告.pdf

:: 指定輸出檔名
"JH PDF2MD.exe" 報告.pdf -o 輸出\報告.md

:: 轉換整個資料夾（-r 包含子資料夾），結果放到另一個資料夾
"JH PDF2MD.exe" 文件資料夾 -o 輸出資料夾 -r

:: 只轉換部分頁面，不擷取圖片
"JH PDF2MD.exe" 報告.pdf --pages 1-5,8,20- --no-images
```

在 PowerShell 中請寫成 `& ".\JH PDF2MD.exe" 報告.pdf`。

| 參數 | 說明 |
| --- | --- |
| `-o, --output` | 輸出的 `.md` 檔；有多個輸入時是輸出資料夾。預設與 PDF 放在同一個資料夾 |
| `-r, --recursive` | 連同子資料夾中的 PDF 一起處理 |
| `--pages` | 只轉換指定頁面，例如 `1-3,5,10-` |
| `--no-images` | 不擷取圖片 |
| `--no-tables` | 不偵測表格，大型文件可以加快速度 |
| `--keep-headers` | 保留頁首、頁尾與頁碼 |
| `--page-breaks` | 在每一頁之間插入分隔線 `---` |
| `--sort` | 依版面位置（由上而下、由左而右）重新排列文字。適合文字順序錯亂的 PDF，多欄排版請勿使用 |
| `--password` | 加密 PDF 的密碼 |

## 轉換規則

| PDF 中的內容 | 轉換結果 |
| --- | --- |
| 字級明顯大於內文的文字 | `#` 到 `######` 標題，字越大層級越高 |
| 單獨一行、與內文同大小的粗體短句 | 最低一層的標題 |
| 粗體、斜體 | `**粗體**`、`*斜體*` |
| 等寬字型（Courier、Consolas 等） | 行內程式碼；連續多行會變成程式碼區塊並保留縮排 |
| `•`、`-`、`▪` 等項目符號 | `- 項目`，並依縮排位置產生巢狀清單 |
| `1.`、`2)` 等編號 | `1. 項目` |
| 有框線的表格 | Markdown 表格，第一列當作表頭 |
| 圖片 | 另存成檔案，以 `![](...)` 嵌入 |
| 超連結 | `[文字](網址)` |
| 每頁重複的頁首、頁尾、頁碼 | 移除 |
| 被換行或換頁切斷的段落 | 接回成一段。英文行尾的連字號斷字會還原，中文與日文換行處不補空白 |

## 已知限制

- **掃描檔**：沒有文字層的 PDF 只能取出圖片。請先用 OCR 軟體（例如 Adobe Acrobat 或 Tesseract）處理。程式會提示哪些頁面沒有文字。
- **無框線表格**：只能偵測有格線的表格，沒有框線的表格會變成一般段落。
- **多欄與複雜版面**：文字依 PDF 內部的順序輸出，多數文件是正確的。如果順序錯亂，可以試試 `--sort`。
- **數學公式**：以純文字輸出，不會轉成 LaTeX。
- 標題和段落是依字級、粗體、行距等版面特徵推測的，排版特殊的文件可能需要手動調整。

## 從原始碼執行

需要 Python 3.10 以上版本。

```bat
pip install -r requirements.txt
python pdf2md.py 報告.pdf
```

參數與執行檔完全相同。`pdf2md.bat` 提供同樣的拖放功能，只是改用系統上的 Python 執行。

### 自行打包執行檔

執行 `build.bat`，它會：

1. 在 `build\venv` 建立乾淨的虛擬環境，只安裝 PyMuPDF 和 PyInstaller，避免把不相干的套件包進去。
2. 用 PyInstaller 產生 `dist\JH PDF2MD.exe`。

`build` 資料夾只是打包過程的暫存，完成後可以整個刪除。

### 專案結構

| 檔案 | 用途 |
| --- | --- |
| `pdf2md.py` | 主程式，全部的轉換邏輯都在這個檔案 |
| `pdf2md.bat` | 用系統 Python 執行主程式的拖放入口 |
| `build.bat` | 打包成 `JH PDF2MD.exe` |
| `requirements.txt` | 相依套件 |
